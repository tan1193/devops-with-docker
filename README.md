# DevOps with Docker Exercises

This repository contains a collection of exercises designed to help you learn and practice DevOps concepts using Docker and Docker Compose.

## Structure of the Repository

The exercises are organized into two main parts:

*   **Part 1: Docker Fundamentals**
    *   This part focuses on the basics of Docker, including `Dockerfile` creation (e.g., `FROM`, `RUN`, `COPY`, `CMD`), building custom images, running containers, managing persistent data with volumes, and other fundamental Docker commands and concepts.
    *   Exercises are located in subdirectories like `part1/1.1/`, `part1/1.2/`, and so on.
*   **Part 2: Docker Compose**
    *   This part introduces Docker Compose for defining and managing multi-container applications. You'll learn how to connect services, manage their lifecycles together, and scale services.
    *   Exercises are located in subdirectories like `part2/2.1/`, `part2/2.2/`, etc.

Each subdirectory (e.g., `part1/1.1/`) represents a specific exercise or example.

## How to Use

1.  **Navigate to an Exercise:** Change your directory to the specific exercise you want to work on (e.g., `cd part1/1.1`).
2.  **Check for Instructions:** Most exercises have their own `README.md` file with specific instructions, explanations, or goals for that exercise.
3.  **Examine Files:** Look at the `Dockerfile`, `docker-compose.yml`, shell scripts (`.sh`), or any other relevant files within the exercise folder to understand the setup and tasks.
4.  **Run and Experiment:** Follow the instructions, run the Docker commands, build images, start containers, and experiment with the configurations.

## Prerequisites

*   **Docker:** You need to have Docker installed on your system. You can download it from the [official Docker website](https://www.docker.com/get-started).
*   **Docker Compose:** For Part 2 exercises, you will also need Docker Compose. It is usually included with Docker Desktop installations. If you need to install it separately, refer to the [Docker Compose installation guide](https://docs.docker.com/compose/install/).

Happy Dockering!
